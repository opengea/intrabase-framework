# Contributing

Thank you for your interest in Intrabase.

For now this repository does **not accept external pull requests**. We are
preparing a contributor licence agreement (CLA) so that contributions can be
accepted without any doubt about who owns the code. Until it is ready:

- **Bugs and questions**: open an issue.
- **Security problems**: do not open a public issue. Write to the maintainers
  through the contact address on https://www.opengea.org and give us time to fix
  it before publishing anything.
- **Ideas**: issues are welcome; we read them all.

When the CLA is in place this file will explain how to sign it and how to send
changes.
